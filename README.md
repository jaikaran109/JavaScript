## 🚀 How to Use This Repository

1. **Start with Basics** - Begin in the `Basics/` folder to understand fundamental concepts
2. **Follow the Structure** - Progress through folders in this order:
   - Basics → Variables → DataType → Conditionals → Loops → Functions
   - Arrays → Strings → Objects → Callbacks → DOM
3. **Practice** - Each folder contains exercises and "someMoreOperations.js" files with practice problems
4. **Build Projects** - Apply your knowledge using DOM interactions and games

## 💡 Learning Tips

- Read the `.md` files first for theoretical understanding
- Run the `.js` files to see practical examples
- Modify and experiment with the code
- Complete the practice questions (Ques.js files)
- Try to solve problems before looking at solutions

## 📋 File Organization Pattern

Each topic typically includes:
- Basic concepts file(s)
- Markdown guide for theory
- Multiple example/exercise files
- "someMoreOperations.js" for advanced examples
- Practice questions when available
